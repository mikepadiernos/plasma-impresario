# Plasma Opus integrations

**[Integrations](README.md)** · **[Scope](../philosophy/scope.md)** ·
**[Roadmap](../ROADMAP.md)**

Plasma Opus provides a broader productivity context across desktop tools. These
proposed integrations keep mail useful on its own and avoid requiring a specific
companion app.

## Cross-app workflows

| Area               | Intended behavior                                                                                     |
| ------------------ | ----------------------------------------------------------------------------------------------------- |
| Calendar           | Create events from mail and surface availability when scheduling.                                     |
| Contacts           | Open, create and find contacts from sender and recipient details.                                     |
| Notes and journal  | Capture selected message content, follow-ups and action items.                                        |
| Files              | Open, share or forward attachments through appropriate desktop apps.                                  |
| Actions and status | Keep common actions consistent and coordinate reminders and unread state without noisy interruptions. |

## Workspace context

Associate mail accounts with workspaces and their Plasma Activities. Where
relevant, use workspace or task context to support triage, focus and
work-time-specific behavior.

> [!NOTE]
>
> Workspace and cross-app behavior are planned. Define permissions, privacy,
> recovery and graceful fallback when companion services are unavailable.
