# Shell and interaction refinement

This section covers refinement of navigation, panes, layouts, keyboard flow, and general interaction quality.

## Focus

- Refine navigation, panes, toolbars, layouts, density, focus states, and keyboard interaction
- Preserve pane sizes, visibility, and focus across restarts and layout changes
- Make primary actions discoverable without crowding compact layouts
- Verify keyboard-only navigation, visible focus, and predictable focus restoration after dialogs and actions

## Acceptance criteria

- The app remains understandable in compact, comfortable, and focus modes.
- Keyboard users can navigate the shell without visual ambiguity.
- Layout changes remain stable and restore cleanly after restart or reconnect.
- Menus and toolbar actions remain synchronized with the current account, folder, and selection.
