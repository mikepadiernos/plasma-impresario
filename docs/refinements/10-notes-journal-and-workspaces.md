# Notes, journal, and workspaces refinement

This section covers refinement criteria for potential notes, journal, editor, and cross-app workspace behavior.

## Focus

- Define refinement criteria for potential notes, journal, the Plasma Opus editor, and cross-app workspace behavior
- Define editor criteria for keyboard navigation, draft recovery, formatting consistency, and accessible text entry
- Define note and journal criteria for search, organization, autosave feedback, and storage privacy
- Specify potential workspace context switching, account boundaries, and state restoration across apps
- Define compatibility and failure expectations for sharing editor or workspace context with Plasma Opus

## Acceptance criteria

- Companion workflows remain optional and gracefully degrade when unavailable.
- Notes and journal capture flows preserve context and recover user work reliably.
- Workspace context support remains understandable and privacy-aware.
- Cross-app handoff remains helpful without becoming fragile or invasive.
