# Compose toolbar

This toolbar appears in the message composer and supports drafting, recipients, and send actions.

```text
└─ Compose toolbar
   ├─ Left side
   │  ├─ Save draft
   │  ├─ Attach files
   │  ├─ Add recipient
   │  ├─ Insert signature
   │  ├─ Format text
   │  └─ Spellcheck
   ├─ Center
   │  ├─ Send now
   │  ├─ Send later
   │  ├─ Schedule send
   │  └─ Save as template
   └─ Right side
      ├─ Switch to plain text / rich text
      ├─ Validate recipients
      ├─ Check attachment safety
      └─ Compose settings
```

## Behavioral rules
- The send action must remain the most prominent, visible, and trustworthy control.
- Draft safety and attachment safety should be easily accessible.
- Formatting controls should remain compact, especially for keyboard and desktop users.

## Purpose

This is the writing action surface for the message composer. It should support focused composing while keeping the send flow clear and reliable.
