# Reading pane toolbar

This toolbar appears in the message reading area and supports message-level actions while reading.

```text
└─ Reading pane toolbar
   ├─ Left side
   │  ├─ Reply
   │  ├─ Reply all
   │  ├─ Forward
   │  ├─ Mark as read
   │  ├─ Flag
   │  └─ Archive
   ├─ Center
   │  ├─ Open source
   │  ├─ Show details
   │  ├─ Previous message
   │  ├─ Next message
   │  └─ Return to list
   └─ Right side
      ├─ Move to folder
      ├─ Delete
      ├─ Print
      ├─ Save attachment(s)
      └─ Share / external action menu
```

## Behavioral rules
- The toolbar should remain focused on the currently displayed message and nearby reading flow.
- It should not duplicate every folder or bulk-action command from the message list.
- The most common actions should remain close to the reading pane and visually clear.

## Purpose

This is the main reading experience action bar. It supports the user’s core message tasks without cluttering the message content itself.
